# 命途扉页 — SillyTavern 聊天楼层导航器

聊了几百上千楼，想回顾某段经典剧情却要手动滑半天？这个插件帮你一键直达。

## 功能

- **楼层跳转**：输入楼层号直接跳转
- **区间定位**：输入如 `30-100`，跳转到起始楼层并标记区间边界
- **顶部/底部**：一键回到第 0 楼或最新楼层
- **关键词搜索**：搜索消息正文和日期，包含隐藏楼层
- **发言人过滤**：按"全部/用户/角色/隐藏"筛选搜索结果
- **书签收藏**：给经典楼层打标签，随时一键跳转
- **区间导出**：支持 `.md` / `.txt` / `.jsonl` 三种格式，可导出文件或复制到剪贴板

## 安装

### 方式一：通过链接安装（推荐）

1. 在 SillyTavern 中打开 **扩展** → **安装扩展**
2. 输入本仓库地址：
   ```
   https://github.com/bkbk258/SillyTavern-ChatNavigator
   ```
3. 点击安装，重启 SillyTavern 即可

### 方式二：手动安装

将整个仓库克隆或下载到 SillyTavern 的第三方扩展目录：

```
SillyTavern/public/scripts/extensions/third-party/SillyTavern-ChatNavigator/
```

然后重启 SillyTavern。

## 使用

1. 聊天界面右侧会出现一个 📖 按钮
2. 点击展开导航面板
3. 面板分四个标签页：导航、搜索、书签、导出

## 楼层编号

与 SillyTavern 内部一致，从 **0** 开始编号。

## 关于隐藏楼层

用户隐藏的楼层（用于节省模型上下文）仍然保存在聊天数据中，**搜索时完全可以搜到隐藏楼层的内容**。跳转时如果目标楼层 DOM 未渲染，会自动跳转到最近的可见楼层并提示。

## 性能

- 搜索使用 300ms 防抖，适配大几千楼聊天
- 搜索结果分页显示（每页 50 条），避免卡顿
- 使用 SillyTavern 官方 Context API，兼容性好
